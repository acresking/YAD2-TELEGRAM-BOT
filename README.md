## 🌟 תכונות מרכזיות
- 🛡️ **סינון סוכנויות ומתווכים חכם**: שלילה אוטומטית של מגרשי רכב, סוכנויות, הצעות מימון, עסקאות טרייד-אין ומתווכים (ללא פסילת מוכרים פרטיים שרושמים "לא לסוכנויות").
- 🚗 **שליפת נתוני רכב מלאים מדף המודעה**:
  - כותרת מלאה ותת-דגם / גרסה
  - מחיר נקוב מעודכן
  - שנתון + חודש עלייה מדויק לכביש (למשל: `2021 (עלייה לכביש: 05/2021)`)
  - תאריך תוקף טסט אחרון (למשל: `08/2027`)
  - מספר יד וסוג בעלות (פרטית, ליסינג, חברה)
  - קילומטראז' מעוצב
  - מפרט מנוע (נפח סמ"ק, כ"ס, תיבת הילוכים וסוג דלק)
  - ציון ודירוג בטיחות הרכב (מתוך 10)
  - עיר, אזור ושכונה
  - שם איש הקשר ומספר טלפון לחיץ לחיוג ישיר (`tel:`)
  - תאריך ושעת פרסום המודעה
  - תיאור המוכר המלא
  - קישור ישיר למודעה באתר יד 2
- 📸 **תמונות באיכות גבוהה**: שליחת התמונה הראשית ככרטיס תמונה ייעודי בטלגרם.
- 🎯 **סינון מרובה (Multi-Select)**: בחירת מספר יצרנים ומספר אזורים בו-זמנית בעזרת מקלדת כפתורים אינטראקטיבית (`[✅/⬜]`).
- 🔄 **מניעת כפילויות**: מודעה שכבר נשלחה לא תישלח שוב, עם אפשרות לאיפוס היסטוריה בלחיצת כפתור (`/clear_history`).
- 🔔 **בדיקת חיבור מיידית**: שליחת הודעת אישור אוטומטית בעת חיבור ערוץ חדש.

## 🔑 מדריך השגת פרטי החיבור

### שלב א': הוצאת Cookie ו-User-Agent מאתר יד 2
אתר יד 2 מוגן במנגנון אבטחה של Cloudflare. כדי שהבוט יוכל לגשת לנתונים, נדרש להעתיק את ה-Cookie וה-User-Agent מהדפדפן שלכם:

1. פתחו את דפדפן **Google Chrome** (או Edge / Firefox) והיכנסו לאתר [יד 2 - רכבים](https://www.yad2.co.il/vehicles/cars).
2. לחצו על מקש **F12** במקלדת (או קליק ימני בעכבר בכל מקום בדף ובחרו ב-**Inspect / בדיקה**).
3. בתפריט העליון של חלון המפתחים שנפתח, עברו ללשונית **Network** (רשת).
4. רעננו את הדף (לחצו על **F5**).
5. בתיבת הסינון (Filter) למעלה, לחצו על **Fetch/XHR** או חפשו `cars`.
6. לחצו על אחת הבקשות הראשונות ברשימה (למשל: `cars` או `feed-search`).
7. בחלונית הימנית שנפתחת, תחת הלשונית **Headers**, גללו מטה לחלק שנקרא **Request Headers**:
   - **העתקת ה-Cookie**: מצאו את השורה שמתחילה ב-`Cookie:`, לחצו עליה קליק ימני ובחרו **Copy value** (העתיקו את כל המחרוזת הארוכה).
   - **העתקת ה-User-Agent**: באותו חלק של Request Headers, מצאו את השורה `User-Agent:` והעתיקו את הערך שלה.

> 💡 **טיפ:** ה-Cookie תקף לזמן ממושך. אם הבוט מפסיק לקבל מודעות לאחר שבועות או חודשים, פשוט מעתיקים Cookie מעודכן מהדפדפן ומעדכנים בקובץ `.env`.

### שלב ב': יצירת בוט בטלגרם וקבלת טוקן (Token)
1. פתחו את אפליקציית טלגרם וחפשו את הבוט הרשמי של טלגרם: [@BotFather](https://t.me/BotFather).
2. שלחו לו את הפקודה: `/newbot`.
3. תנו לבוט שם (למשל: `Yad2 Alerts Bot`) ושם משתמש שמסתיים ב-`bot` (למשל: `my_yad2_alerts_bot`).
4. `BotFather` יחזיר לכם הודעה עם **API Token** שנראה כך:
   `6592235497:AAERXUNLd036DbDPdJqVZKsjOzJ-ODlI8hk`

### שלב ג': חיבור הבוט לערוץ טלגרם
1. צרו ערוץ חדש בטלגרם (פרטי או ציבורי).
2. היכנסו להגדרות הערוץ -> **Administrators (מנהלים)** -> **Add Admin (הוסף מנהל)**.
3. חפשו את שם המשתמש של הבוט שלכם והוסיפו אותו כמנהל עם הרשאת **Post Messages (פרסום הודעות)**.
4. כשתגדירו חיפוש חדש בבוט:
   - **לערוץ פרטי:** העבירו (Forward) הודעה כלשהי מהערוץ לצ'אט עם הבוט.
   - **לערוץ ציבורי:** שלחו לבוט את שם הערוץ (למשל: `@my_channel`).
   - **לצ'אט הפרטי:** פשוט לחצו על הכפתור "📩 שלח לכאן".
5. הבוט ישלח מיד **הודעת בדיקה לערוץ** לאישור שהחיבור וההרשאות תקינים.

## 🚀 התקנה והרצה מהירה

### 1. הורדת הקוד והתקנת סביבה
```bash
# שכפול ה-Repository
git clone [https://github.com/your-username/yad2-telegram-bot.git](https://github.com/your-username/yad2-telegram-bot.git)
cd yad2-telegram-bot

# יצירת סביבה וירטואלית
python -m venv .venv

# הפעלת הסביבה הווירטואלית ב-Windows:
.venv\Scripts\activate

# או ב-Linux / Mac:
source .venv/bin/activate

# התקנת הספריות הנדרשות
pip install python-telegram-bot requests python-dotenv

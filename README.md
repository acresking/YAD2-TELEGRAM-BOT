# 🚗 Yad2 Real-Time Multi-Alert Telegram Bot

בוט טלגרם חכם לסריקה וניטור מודעות רכב ונדל"ן פרטיות מאתר **יד 2 (Yad2)** בזמן אמת, עם שליחה אוטומטית לערוצים פרטיים, ציבוריים או צ'אטים ישירים.

---

## 🌟 תכונות מרכזיות
- 🛡️ **סינון סוכנויות ומתווכים**: מנגנון חכם לשלילת מגרשים, סוכנויות רכב, הצעות מימון, טרייד-אין ומתווכים.
- 🚗 **שליפת נתוני רכב מלאים מדף המודעה**:
  - כותרת מלאה ותת-דגם / גרסה
  - מחיר נקוב
  - שנתון מדויק + חודש עלייה לכביש
  - תאריך תוקף טסט אחרון
  - מספר יד וסוג בעלות (פרטית / ליסינג / חברה)
  - קילומטראז'
  - מפרט מנוע (נפח סמ"ק, כ"ס, תיבת הילוכים וסוג דלק)
  - ציון ודירוג בטיחות הרכב
  - עיר, אזור ושכונה
  - שם איש הקשר ומספר טלפון לחיץ לחיוג ישיר (`tel:`)
  - תאריך ושעת פרסום המודעה
  - תיאור המוכר המלא
  - קישור ישיר למודעה באתר יד 2
- 📸 **תמונות באיכות גבוהה**: שליחת התמונה הראשית ככרטיס תמונה ייעודי בטלגרם.
- 🎯 **סינון מרובה (Multi-Select)**: בחירת מספר יצרנים ומספר אזורים בו-זמנית בעזרת מקלדת כפתורי סימון (`[✅/⬜]`).
- 🔄 **מניעת כפילויות**: מודעה שכבר נשלחה לא תישלח שוב, עם אפשרות לאיפוס היסטוריה בלחיצת כפתור.
- 🔔 **בדיקת הרשאות בערוץ**: שליחת הודעת בדיקה מיידית בעת חיבור ערוץ חדש.

---

## 🚀 התקנה והרצה מקומית

### 1. דרישות קדם
- **Python 3.10** ומעלה.
- בוט טלגרם פעיל (נוצר דרך [@BotFather](https://t.me/BotFather)).

### 2. שכפול הפרויקט והתקנת תלויות
```bash
git clone [https://github.com/your-username/yad2-telegram-bot.git](https://github.com/your-username/yad2-telegram-bot.git)
cd yad2-telegram-bot

# יצירת סביבה וירטואלית
python -m venv .venv

# הפעלת הסביבה הווירטואלית (Windows)
.venv\Scripts\activate

# הפעלת הסביבה הווירטואלית (Linux / Mac)
source .venv/bin/activate

# התקנת הספריות הנדרשות
pip install python-telegram-bot requests python-dotenv
